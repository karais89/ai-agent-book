### 핵심 개념: 에이전트 = LLM + 컨텍스트 + 도구

이 책의 핵심 프레임워크는 **에이전트 = LLM + 컨텍스트 + 도구**다. 세 요소가 협력해
에이전트의 지능적 행동을 구현한다.

- **LLM**: 이해, 사고, 의사 결정 능력을 제공하는 에이전트의 두뇌다.
- **컨텍스트**: 시스템 지침, 대화 기록, 사고 과정, 도구 상호작용 기록 등을 담는 에이전트의 운영 체제다.
- **도구**: 환경을 인식하고 행동을 실행하며 외부 세계와 상호작용하게 하는 에이전트의 손발이다.

### 학습 경로

학습 경로는 책의 장 구성과 일치하며 세 축을 중심으로 단계적으로 전개된다.

- **1장 · 기초**: 강화 학습 관점의 에이전트 정의, 전통적 강화 학습과 LLM+RL 패러다임의 샘플 효율성 차이, “모델이 곧 에이전트”인 새 패러다임을 이해하고 **에이전트 = LLM + 컨텍스트 + 도구**라는 핵심 프레임워크를 익힌다. **핵심 통찰**: 사전 지식은 알고리즘과 환경보다 더 중요하다.

- **2~3장 · 컨텍스트**: 컨텍스트는 에이전트의 운영 체제다. 2장에서는 시스템 프롬프트, KV 캐시에 유리한 설계, 컨텍스트 압축, 프롬프트 엔지니어링 절제 실험을 다룬다. 3장에서는 사용자 메모리, 밀집·희소·하이브리드 검색, 에이전틱 RAG, 컨텍스트 기반 검색, 구조화 지식 추출을 다룬다. **핵심 통찰**: 완전한 컨텍스트에는 시스템 지침, 대화 기록, 사고 과정, 도구 상호작용 기록, 사용자 메모리, 외부 지식이 모두 포함된다.

- **4~5장 · 도구**: 도구는 에이전트와 세계를 연결하는 다리다. 4장에서는 세 종류의 MCP 도구(인식·실행·협업), 이벤트 트리거, 비동기 아키텍처를 다룬다. 5장에서는 프로덕션급 코딩 에이전트의 전체 구현을 깊이 살펴본다. **핵심 통찰**: 도구는 범용적으로 설계해야 하며 계산기보다 코드 인터프리터가 낫다. 코드는 새 도구를 만드는 메타 능력이다.

- **6~7장 · 모델**: 지능을 측정하고 증폭하는 방법을 배운다. 6장에서는 Terminal-Bench, SWE-bench, GAIA, OSWorld, Tau2-Bench 같은 평가 벤치마크를 다룬다. 7장에서는 SFT, RL, RLHF, 샘플 효율성 등 사후 학습 기법을 다룬다. **핵심 통찰**: 독립적인 검증 신호는 “모델에게 다시 생각하라고 요청하는 것”보다 믿을 만하다. “모델이 곧 에이전트”인 패러다임에서는 강화 학습을 통해 도구 호출을 모델의 고유 능력으로 내재화한다.

- **8장 · 지속적 진화**: 가중치를 바꾸지 않고도 경험에서 성장하는 에이전트를 만든다. 경험 학습, 워크플로를 도구로 외부화하는 방법, 프롬프트와 관찰을 매개변수로 증류하는 방법을 다룬다. **핵심 통찰**: 경험 학습은 에이전트가 단순히 “똑똑한” 상태에서 실제로 “숙련된” 상태로 나아가는 열쇠다.

- **9~10장 · 확장과 협업**: 9장은 인식과 행동의 범위를 텍스트에서 음성, GUI, 물리 세계로 확장한다. 10장은 멀티 에이전트의 분업으로 복잡한 과업을 해결한다. **핵심 통찰**: 멀티 에이전트 시스템의 모든 설계 결정은 단일 에이전트의 세 요소에서 대응 관계를 찾을 수 있다.

### 난이도

- **입문**(1~2장): 기본 개념을 익히려는 초보자에게 적합하다.
- **중급**(3~4장): 프로그래밍 기초가 필요하며 시스템 통합을 다룬다.
- **고급**(5~6장): 탄탄한 프로그래밍 역량이 필요하며 복잡한 시스템 설계를 다룬다.
- **전문**(7~8장): 딥러닝과 학습·지속적 진화 경험이 필요하다.
- **응용**(9~10장): 앞에서 배운 내용을 종합해 실용 애플리케이션을 만든다.

### 실습 방법

1. **직접 실행하기**: 각 프로젝트는 독립적으로 실행할 수 있게 설계되어 있다. 코드를 직접 실행하고 수정해 본다.
2. **본문과 함께 보기**: 이 저장소의 한국어 [`book/`](../../book/) 또는 영어 [`book-en/`](../../book-en/) 본문을 함께 읽어 이론과 실습의 연결을 이해한다.
3. **비교 실험하기**: 많은 프로젝트에 절제 연구와 비교 실험이 포함되어 있다. 결과를 비교하며 이해를 깊게 한다.
4. **단계적으로 학습하기**: 단순한 프로젝트부터 시작해 점차 복잡한 시스템으로 나아간다.
5. **프로토콜에 주목하기**: 4장의 MCP 서버 프로젝트는 확장 가능한 에이전트를 만드는 핵심인 표준화된 도구 프로토콜을 보여 준다.
