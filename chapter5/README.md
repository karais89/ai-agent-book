# 5장 · 코딩 에이전트와 코드 생성

> 코드는 ‘새로운 도구를 만들 수 있는 도구’이며 범용 에이전트의 메타 능력이다. 프로덕션급 코딩 에이전트를 사례로 삼아 가장 강력한 범용 도구를 완전하게 구현하는 방법을 보여 준다.

← [메인 README로 돌아가기](../README.md) · 📖 [장 본문 읽기](../book/chapter5.md)

## 부속 프로젝트

| 실험 | 프로젝트 | 유형 | 설명 |
| :--: | --- | :--: | --- |
| 5-1 | [code-for-math](code-for-math/) | ✅ | 같은 모델과 같은 경시대회 수학 문제 집합에서 ‘순수 사고의 연쇄’와 ‘코드 보조’ 방식을 비교한다. 후자는 문제를 Python(sympy/numpy/scipy)으로 정형화하고 하위 프로세스 샌드박스에서 함수 호출로 실행해 오류가 잦은 암산을 정확한 계산으로 대체함으로써 정확도를 크게 높인다. |
| 5-2 | [code-for-logic](code-for-logic/) | ✅ | ‘기사와 악당’ 논리 퍼즐을 제약 충족 문제(CSP)로 바꾼다. 에이전트가 `python-constraint`로 변수와 쌍조건 제약을 정의한 뒤 풀이기를 호출한다. 퍼즐 집합에서 순수 자연어 사고와 코드 보조 방식의 정확도를 비교한다. |
| 5-3 | [small-model-codified-rules](small-model-codified-rules/) | ✅ | τ-bench 항공 고객 서비스 시나리오에 기반한 통제 실험이다. 복잡한 비즈니스 정책(환불 규칙)을 자연어 프롬프트에서 코드·도구로 옮기자 소형 모델의 작업 성공률과 정책 준수율이 크게 향상된다. 도구 내부 코드 검증이 모델의 잘못된 판단을 실시간으로 차단할 수 있다. |
| 5-4 | [paper-to-ppt](paper-to-ppt/) | ✅ | ‘PPT 만들기’를 코드 생성 문제로 재정의한다. 제안자는 Slidev(Markdown+HTML) 코드를 작성하고 검토자는 각 페이지를 PNG로 렌더링한 뒤 비전 LLM으로 레이아웃 문제를 확인하며 구조화된 피드백에 따라 반복 수정한다. 두 에이전트의 역할 분담으로 최대 컨텍스트 크기를 크게 줄인다. |
| 5-5 | [paper-to-video](paper-to-video/) | ✅ | ‘논문 → PPT’를 바탕으로 슬라이드마다 구어체 해설 대본을 만들고 TTS로 음성을 합성한 뒤, ffmpeg로 각 슬라이드 화면과 음성을 페이지별로 동기화하여 내레이션이 있는 해설 영상을 만든다. |
| 5-6 | [video-edit](video-edit/) | ✅ | 여러 장면이 있는 영상과 자연어 요청이 주어지면 에이전트가 ‘2단계 비전 위치 탐색’(거친 프레임 추출에서 정밀 프레임 판독으로 진행)으로 목표 장면의 시간 경계를 찾는다. 구간을 자른 뒤 검토자가 결과 클립의 핵심 프레임을 추출해 검증하고 만족스럽지 않으면 다시 반복한다. |
| 5-7 | [adaptive-log-parser](adaptive-log-parser/) | ✅ | 스스로 진화하는 로그 파싱 시스템이다. 해석할 수 없는 새 형식을 만나도 오류를 내는 대신 실패 샘플과 오류 메시지를 코드 생성 에이전트에 전달해 `parse` 함수를 만든다. 자동 테스트를 통과하면 함수를 핫 업데이트하여 파싱 엔진에 등록하며 전체 과정에 사람이 개입하지 않는다. |
| 5-8 | [log-diagnosis](log-diagnosis/) | ✅ | 진단 에이전트가 프로덕션 추적 로그, 아키텍처 문서, PRD를 읽고 문제와 근본 원인을 자동으로 찾아 구조화된 보고서와 회귀 테스트를 만든다. 재생 프레임워크로 실제 실행을 검증하고 MCP 연동을 통해 모의 GitHub 이슈를 생성한다. |
| 5-9 | [dynamic-form](dynamic-form/) | ✅ | 불완전한 요청을 받았을 때 에이전트가 질문을 하나씩 하지 않고 연쇄 로직이 포함된 독립형 HTML 양식을 동적으로 만든다. 사용자는 빠진 정보를 한 번에 입력하고, 프런트엔드는 양식 데이터를 JSON으로 모아 에이전트에 돌려주어 작업을 계속하게 한다. |
| 5-10 | [erp-agent](erp-agent/) | ✅ | 중국어 자연어 질의를 SQL로 변환해 데이터베이스에서 실행하고 결과 표를 바로 보여 준다. 핵심은 LLM이 데이터 자체를 옮기지 않고 SQL 산출물만 생성하는 아티팩트 패턴이다. 토큰을 절약하고 수동 계산 오류를 피하며, 수만 행의 결과도 즉시 반환할 수 있다. |
| 5-11 | [conversational-ui](conversational-ui/) | ✅ | 사용자가 색상, 글꼴, 문구, 레이아웃 같은 UI 맞춤 요청을 자연어로 제시하면 에이전트가 React 프런트엔드 소스 코드를 자율적으로 찾아 수정한다. Vite의 HMR(Hot Module Replacement)을 활용해 변경이 즉시 반영되며 여러 턴에 걸친 반복 맞춤을 지원한다. |
| 5-12 | [coding-agent](coding-agent/) | ✅ | Claude를 기반으로 한 프로덕션급 AI 코딩 도우미로, 명령줄 의존성 없이 순수 Python만으로 구현했다. 파일 조작, 검색, 셸 작업, 프로젝트 관리를 아우르는 완전한 도구 17개를 제공하고 ripgrep 기능과 완전히 호환되는 순수 Python Grep 도구를 포함한다. |
