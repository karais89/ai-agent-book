# 6장 · 에이전트 평가

> 에이전트 성능을 비교 가능한 신호로 바꾼다. 평가 환경, 데이터셋 설계, 지표 체계, 통계적 유의성, 관측 가능성, 평가 기반 선택, 프로덕션급 내부 평가와 시뮬레이션 환경을 다룬다.

← [메인 README로 돌아가기](../README.md) · 📖 [장 본문 읽기](../book/chapter6.md)

## 부속 프로젝트

| 실험 | 프로젝트 | 유형 | 설명 |
| :--: | --- | :--: | --- |
| 6-1, 6-2 | `tau2-bench/` | 📖 | 계산, 검색, 데이터 처리 같은 시나리오에서 에이전트가 복잡한 사고에 도구를 사용하는 능력을 평가한다. |
| 6-2 | `terminal-bench/` | 📖 | 실제 터미널 환경에서 AI 에이전트의 성능을 시험하는 벤치마크다. 코드 컴파일, 모델 학습, 서버 설정 등 실제 엔드투엔드 작업을 처리하는 능력을 평가한다. 약 100개 작업으로 이루어진 데이터셋과 실행 프레임워크를 포함하며 여러 에이전트 구현을 지원한다. |
| 6-2 | `SWE-bench/` | 📖 | 대규모 언어 모델이 실제 GitHub 이슈를 해결하는 능력을 평가하는 벤치마크다. 코드베이스와 이슈 설명이 주어지면 모델은 문제를 해결하는 패치를 생성해야 한다. SWE-bench, SWE-bench Lite, SWE-bench Verified, SWE-bench Multimodal 등 여러 버전이 있다. |
| 6-2 | `GAIA/` | 📖 | 도구 보강, 효율적인 프롬프팅, 검색 접근 등을 갖춘 차세대 LLM을 평가한다. 답이 명확하면서도 여러 수준의 도구 사용과 자율성이 필요한 450개 이상의 비단순 질문으로 이루어지며 난이도는 세 단계다. |
| 6-2 | `OSWorld/` | 📖 | 완전한 운영체제 환경에서 파일 관리, 애플리케이션 조작, 시스템 설정 같은 복잡한 작업을 수행하는 에이전트의 능력을 평가한다. |
| 6-2, 6-10 | `android_world/` | 📖 | 앱 탐색, UI 상호작용, 작업 완료 등 Android 모바일 환경에서 에이전트의 성능을 평가한다(외부 벤치마크 저장소). |
| 6-5 | [tts-quality-eval](tts-quality-eval/) | ✅ | 여러 TTS 설정(서로 다른 모델·음성·속도)으로 같은 난해한 텍스트 집합을 합성한 뒤, 멀티모달 LLM 심사자(LLM-as-a-Judge)가 루브릭에 따라 명료성, 자연스러움 등의 항목을 채점한다. 결과를 재현 가능한 설정 비교표로 집계한다. |
| 6-6 | [elo-leaderboard](elo-leaderboard/) | ✅ | Elo 평점 체계 기반의 에이전트 성능 리더보드를 구현하여 쌍대 비교로 서로 다른 에이전트의 상대 능력을 평가한다. |
| 6-7 | [agent-cost-analysis](agent-cost-analysis/) | ✅ | 전형적인 다중 턴 에이전트 작업(고객 서비스 환불)의 전체 비용을 세분화한다. 가벼운 맞춤 추적 시스템으로 각 LLM 호출의 입출력·캐시 토큰, 지연 시간, 비용을 기록하고 ‘어느 단계가 가장 비싼가’를 집계한다. 이어 A/B 테스트로 KV 캐시 친화적 설계와 컨텍스트 압축의 실제 절감 효과를 정량화한다. |
| 6-8 | [model-benchmark](model-benchmark/) | ✅ | 여러 OpenAI 호환 LLM API 제공자를 가로로 비교한다. 스트리밍 인터페이스로 첫 토큰 시간(TTFT)을 정밀 측정하고 동시 실행 시 엔드투엔드 지연 시간 백분위수(p50/p95), 처리량, 성공률을 계산한다. 명령 하나로 다차원 비교표를 만들어 모델 선택이 리더보드 하나만 보는 문제가 아니라 여러 측면의 상충 관계임을 보여 준다. |
| 6-10 | [android-world](android-world/) | 📖 | AndroidWorld에 관한 저장소 내부의 T3A 평가 보고서와 실패 분석 노트다(실험 6-10의 출발점이며 벤치마크 원본이 아님). |
| — | [public-health-reporting-eval](public-health-reporting-eval/) | ✅ | DHIS2 형식의 합성 집계 데이터로 공중보건 보고 에이전트의 도구 호출, 계산 정확성, 근거 인용, 근거 없는 주장을 객관적으로 평가한다. |

> 백틱으로 표시한 외부 벤치마크는 별도로 복제해야 한다. 하이픈이 들어간 [`android-world/`](android-world/)는 이 저장소의 **T3A 평가 분석 노트**이며([README](android-world/README.md) 참고), 외부 `android_world/` 벤치마크 원본과는 다른 경로다.
